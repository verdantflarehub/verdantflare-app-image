Image MCP 提供图像生成、编辑、状态查询与产物读取。以下为接口能力说明；实际访问由 Studio 授权。

image.create Tool

标准异步生图接口。参数接收 prompt、aspect_ratio、resolution (2k/4k)、engine 及 model，输出任务编号及落盘产物。

{ "prompt": "string", "aspect_ratio": "9:16", "resolution": "4k", "engine": "codex", "model": "gpt-image-2.5-sunburst" }
image.edit Tool

图生图与定向微调。基于参考图 source_artifact_id 及多模态指令执行高精度编辑。

{ "source_artifact_id": "string", "prompt": "string", "reference_artifact_ids": [] }
image.inpaint Tool

局部重绘接口。结合底图与 mask_artifact_id 区域遮罩，对指定区域进行无缝融合重绘。

{ "source_artifact_id": "string", "mask_artifact_id": "string", "prompt": "string" }
image.faceswap Tool

真人面部骨相置换微服务调用。基于来源身份图像与目标图像，提交面部置换与可选修复。

{ "target_artifact_id": "string", "source_identity_artifact_id": "string", "restoration_fidelity": 0.85 }
image.statusTool

按任务编号读取状态与元数据，继续跟踪已有任务。

{ "task_id": "string" }
image.resultTool

读取已完成任务的图像产物与受控下载信息。

{ "task_id": "string" }
image.capabilitiesTool

读取已声明渠道、模型与适配限制，不提交生成任务。
